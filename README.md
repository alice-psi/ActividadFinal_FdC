# Glosario General de Terminos

− Algoritmo: Es la secuencia finita [que tiene fin], definida [que cumple un papel 
especifico], y efectivo de operaciones matemáticas y/o procesos.   
− API: Se trata de la interfaz que “traduce” los conjuntos de reglas, definiciones y 
protocolos, permitiendo la interacción entre dos aplicaciones o sistemas. 
− Argumento: Es el valor o dato concreto que sucede a una función; suele estar 
contenido dentro de paréntesis o llaves.   
− Arreglo: Conocido también como "array", vector o matriz, es una colección de 
datos estructurados, finitos y ordenados.   
− Biblioteca (Library): Es el contenedor o colección de código que ya ha sido 
escrito con anterioridad, el cual puede ser reutilizado y organizado en 
programas propios. 
− Bucle: Seria la repetición continua de un proceso o subproceso.  
− Condicional: Es una estructura que controla el flujo logico en diferentes bloques 
de codigos o instrucciones. 
− Callback: Es una función que se pasa a otra función como argumento, con la 
intención de que sea ejecutada después de que ocurra un evento específico o al 
terminar una tarea. 
− Código fuente: Es todo el codigo que estructura un programa con instrucciones 
especficas.   
− Commit: Es el registro de los avances de un proyecto en momentos 
determinados; es también un punto de control/restauración. 
− Compilador: Es un programa que traduce de un lenguaje de programación al 
código máquina o código constructor.
− Condicional: Estructura que permite la toma de decisiones y la ejecución de 
bloques mediante condiciones lógicas (if, else, else if / elif, switch / case). 
− Constante: Es un valor que no cambia, por más modificaciones y/o operaciones 
se le haga a su base.   
− Control de versiones: Es un sistema automático que registra y gestiona los 
cambios que se hacen al código fuente y otros apartados de un proyecto. 
− Depurador (Debugger): Es el sistema que inspecciona y permite corregir errores 
dentro del código, agilizando el proceso de corrección y mejora. 
− Editor de código: Un programa que permite crear, modificar e inspeccionar 
código fuente de un proyecto, público y/o privado. 
− Evento: Un suceso o proceso que el programa detecta desde la acción del 
propio código o que el usuario ejecuta.   
− Expresión: La combinación de valores que el programa detecte como valida.   
− Framework: La estructura predefinida y reutilizable de código que funciona 
como el esqueleto de un programa. 
− Función: Es un bloque de código autónomo que se puede reutilizar para tareas 
específicas. 
− Git: Es un sistema de control de versiones, totalmente gratuito y de código 
abierto; creado por Linus Tovards (creador de Linux) en 2005. 
− GitHub: Una nube de alojamiento de proyectos, pública, de código abierto, y 
basada en Git. 
− IDE: Caja de herramientas fundamental para todo programador, integrada en 
una única interfaz gráfica unificada.
− Intérprete: Similar (aunque no igual) que un compilador, es un traductor que lee, 
analiza y ejecuta código fuente en tiempo real. El proceso de interpretación es el 
siguiente: 
o Lectura e inspección: El intérprete lee la primera instrucción o línea de 
código del archivo fuente. 
o Análisis al vuelo: Verifica que la sintaxis de esa línea sea correcta y 
comprende la instrucción. 
o Ejecución inmediata: Convierte esa línea a instrucciones del sistema 
operativo y procesador y la ejecuta directamente. 
− Ciclo: Pasa a la siguiente línea y repite el proceso hasta llegar al final del 
programa o encontrar un error. 
− JavaScript: Un lenguaje de alto nivel, dinámico y fundamental para el desarrollo 
web. Es el que aporta los comportamientos dinámicos e interactivos de un sitio 
web. 
− Lenguaje de programación: Es un sistema escrito en lenguaje técnico que 
permite al programador comunicarle las instrucciones que requiere que un 
programa realice. 
− Merge: Una función operadora que combina objetos, contenido y/o historial de 
dos o más líneas (ramas) en una sola. 
− Método: Función asociada específicamente a un objeto o a una clase. Los hay 
de diferentes clases; de instancia, que operan con el estado de un objeto; 
estáticos, ejecutándose sin que sea necesario crear objetos nuevos; 
constructores, se ejecutan de manera automática al crearse un objeto nuevo; y 
getters/setters, que son usados para leer (get) o modificar (set) las propiedades 
privadas de un objeto. 
− Objeto: Grupo de datos, comportamientos e instrucciones relacionados entre 
sí; ocupan un espacio dentro de la memoria. 
− Operador: Es una palabra clave que le indica al intérprete o al compilador que 
es necesario realizar una operación matemática/lógica/de manipulación.
− Parámetro: Son variables especiales que están declaradas por una función o 
método que las contiene. 
− Programa: Es un conjunto de instrucciones, escritas en un lenguaje que las 
computadoras pueden entender (lenguaje de programación); requieren de una 
estructura y un orden específicos para que sean interpretados y ejecutados por 
una computadora. 
− Programación asíncrona y programación síncrona: Son paradigmas de diseño; 
la síncrona se ejecuta secuencialmente (Proceso 1 ----> Proceso 2) y detiene 
procesos si estos toman más tiempo de lo común, mientras que la asíncrona se 
ejecuta paralelamente (Proceso 1 <---> Proceso 2) y notifica la finalización de 
procesos en segundo plano. 
− Rama (Branch): Es un medidor temporal el programador utiliza para dividir en 
espacios independientes los avances de un proyecto, aislándolos de otros 
archivos para no alterar el trabajo propio o de un equipo de trabajo. 
− Repositorio: Un repositorio es un espacio o base de datos centralizado que 
guarda archivos, carpetas, imágenes y código relacionado a un proyecto. 
− Retorno: Conocido igualmente como instrucción return, permite a una función o 
método finalizar sus procesos y mostrar un resultado. 
− Sintaxis: Es la estructura, reglamentaria e independiente en cada lenguaje de 
programación (por separado) que les da sentido y orden a las instrucciones. 
− Tipo de dato: En programación, los datos pueden tener varias características. 
Estos pueden ser: Primitivos, Compuestos y Estructurados 
− TypeScript: Lenguaje de código abierto, creado por Microsoft que funciona 
como un superset (lenguaje que engloba y amplía la sintaxis y capacidades de 
otro lenguaje existente) con una compatibilidad estrecha con JavaScript. 
− Variable: Una variable es un dato que puede tener diferentes valores (nunca dos 
al mismo tiempo) y puede modificarse o actualizarse con el tiempo.
